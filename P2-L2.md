En esta práctica he seguido los pasos necesarios para la instalación, configuración y aseguramiento de varios servicios fundamentales en el sistema

Lo primero que he hecho ha sido gestionar los permisos de SELinux para el servicio SSH usando semanage y 
cambiando el puerto de escucha predeterminado al 22022 para mejorar la seguridad. 

Posterior a ello, procedí a la instalación y configuración de la herramienta Fail2ban para proteger el servidor contra ataques de fuerza bruta,
asegurando la creación de los ficheros de configuración locales (fail2ban.local y jail.local) y verificando su correcto funcionamiento con fail2ban-client.

A la hora de desplegar el entorno web y la base de datos, he tomado varias decisiones de configuración. He instalado el servidor web httpd (Apache), 
habilitado su arranque automático al inicio del sistema con systemctl enable httpd y verificado la conectividad mediante curl http://localhost. 
En el cortafuegos, he abierto de forma permanente el puerto HTTP (80/tcp) utilizando firewall-cmd --add-port=80/tcp --permanent y aplicando la recarga de reglas --reload.
Además, he instalado PHP y MariaDB, configurando los parámetros de SELinux mediante setsebool -P httpd_can_network_connect_db=on para permitir que el servidor web se 
comunique correctamente con la base de datos. Para finalizar la seguridad de la base de datos, he ejecutado la herramienta mysql_secure_installation.
