Automatización mediante el script `backup_cliente`

El script backup_cliente tiene como finalidad automatizar el proceso de creación de copias de seguridad. De esta forma, se agrupan 
las distintas operaciones necesarias para realizar el backup en un único procedimiento.

Copia de seguridad de la base de datos

Una parte importante del proceso consiste en realizar un volcado de la base de datos, obteniendo una copia de su contenido que pueda 
utilizarse posteriormente para recuperar la información.

También deben incluirse los historiales de comandos del sistema, como .bash_history y .mysql_history, ya que permiten conservar 
las órdenes ejecutadas tanto en la terminal como en el entorno de MariaDB/MySQL.
Una vez reunidos los archivos necesarios, se pueden empaquetar y comprimir utilizando tar. Esto permite agrupar diferentes archivos y 
directorios en un único fichero de backup, reduciendo además el espacio ocupado mediante la compresión.

Otra herramienta importante para las copias de seguridad es rsync, que permite sincronizar el contenido de un directorio de origen con 
otro de destino, tanto localmente como a través de SSH.
Entre sus opciones destaca -a, que conserva los permisos, propietarios, grupos, fechas y enlaces, además de realizar una copia recursiva. 
También se pueden utilizar el modo -v para mostrar información durante el proceso, -z para comprimir los datos transferidos y --delete 
para eliminar del destino los archivos que ya no existen en el origen.
La restauración de una copia mediante rsync se realiza invirtiendo el orden del origen y el destino.
